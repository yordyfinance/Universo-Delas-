## Como subir no GitHub

1. Crie um repositório novo em https://github.com/new
2. Não marque nenhuma opção de inicialização (sem README, sem .gitignore)
3. Na página do repositório vazio, clique em **"uploading an existing file"**
4. Arraste todos os arquivos desta pasta e clique em **"Commit changes"**

## Como publicar na Vercel

1. Acesse https://vercel.com e faça login (pode usar sua conta do GitHub)
2. Clique em **"Add New..." → "Project"**
3. Selecione o repositório que você acabou de criar no GitHub
4. Em "Framework Preset", deixe como **"Other"** (é um site estático, não precisa de build)
5. Clique em **"Deploy"**
6. Em poucos segundos o site estará no ar com uma URL da Vercel

Qualquer alteração feita nos arquivos do repositório no GitHub gera um novo deploy automático na Vercel.
